# The Weekly Machine — Run-Book

One batch day + scraps. The only streak metric that counts: **batch days completed.** Everything below is the checklist; don't improvise the system, improvise inside it.

## Sunday night (~30 min, or automated later)
- [ ] Run the **research-assistant** agent → this week's trend brief
- [ ] Read it (15 min). Pick ≤2 trend hooks where the trend is a *container* for your joke
- [ ] Watch 3-5 example videos of any chosen trend (15 min — the only mandatory scrolling all week)

## Batch Day (~4 hrs, same day every week — protect it like a flight)

### Block 1 — Package (45 min) — BEFORE anything else
- [ ] **First source: this week's agent conversation.** If a real pain point came up (coffee call, text, comment), the Case of the Week is the main video — see AGENT-BRAIN.md §3. Trend pegs and the evergreen bank are the backup, not the default.
- [ ] Pick 2 video ideas (case of the week + one from trend brief / evergreen bank)
- [ ] Run **research-assistant** topic research on the main one
- [ ] Write title (<50 chars) + thumbnail concept for both. **If you can't make it clickable, it's not a video idea — swap it now, not after recording.**
- Title rules: clear over clever, specific numbers, honest superlatives. Thumbnail: max 3 elements (your face + emotion, one object, ≤3 words).

### Block 2 — Script (45 min)
- [ ] Voice-memo ramble everything you know about the topic (5-10 min, walk around, don't sit)
- [ ] Feed it to **script-writer** → anchor-mode teleprompter script + 3 Shorts + LinkedIn posts
- [ ] Punch up in your own voice (15 min max — done beats perfect)

### Block 3 — Record (60-90 min)
- [ ] Elgato loaded with anchor script, camera behind glass
- [ ] Long-form in as few takes as possible — flubs stay in, the pipeline cuts them. Re-say the line and keep rolling; NEVER stop and restart the recording.
- [ ] 3 Shorts, vertical, separate takes (they're standalone, not clips)
- [ ] 10 seconds of silence at the start (noise profile) + slate each take verbally ("take 2")

### Block 4 — Hand off + LinkedIn (45 min)
- [ ] Drop footage in the project folder, run **video-editor** agent
- [ ] While it processes: finalize the 3-5 LinkedIn posts from script-writer's draft, schedule Tue-Thu 9-11am
- [ ] Make the thumbnail (30 min cap; ugly-but-clear beats pretty-but-vague)

## Midweek (~30-45 min once)
- [ ] Watch the review cut, give change notes (round 1 of max 2)
- [ ] Approve meme placements
- [ ] Schedule: long-form (evening or Sat morning), Shorts spread across 3 days, TikTok/Reels reposts (watermark-free masters)

## Daily (10-15 min, phone timer, then CLOSE THE APP)
- [ ] Reply to every comment on your posts (first hour after a LinkedIn post matters most)
- [ ] 3-5 genuine comments on big real-estate/AI accounts (borrowed distribution — this is how accounts grow from zero)
- [ ] One DM conversation if anyone bit on the week's offer

## Publishing checklist (per video)
- YouTube: keyword-rich title/description, 2-3 hashtags max, end screen → the email offer, pin a comment with the offer CTA
- Shorts/TikTok/Reels: clean masters (no watermarks), platform-native captions checked, 15-30s versions preferred
- LinkedIn: no external links in post body — "comment WORD and I'll DM it"; reply fast in the golden hour
- Everything points at ONE thing: this week's email offer (see OFFERS.md)

## Weekly close (5 min, Friday)
- [ ] Log: batch day done? videos out? emails collected? offer takers?
- [ ] One pipeline improvement note → `pipeline/BACKLOG.md`
- [ ] If two weeks in a row feel like a costume → re-read SOCIAL-GAME-PLAN.md §1 override switch

## The rules that keep it alive
1. **14-day rule:** build nothing you won't personally use within 14 days.
2. **Batch day is sacred.** If life explodes, the fallback is ONE Short recorded on your phone — the streak survives on the minimum viable unit.
3. **Two review rounds max**, then it ships.
4. **First 10 videos are tuition.** YouTube judges each video fresh; flops don't follow you.
5. **Scoreboard = batch days, emails, offers claimed.** Not subs. Check sub counts on Fridays only.
